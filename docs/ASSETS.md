# 素材需求文档 · 骗子酒馆

这份文档给做 3D / 音频素材的人看。照做即可，不需要了解代码。

项目里**角色数量不写死**：给几个模型，游戏里就有几个角色，加角色不用改引擎逻辑。

---

## 一、最小可用集（P0）

没有这些跑不起来：

| 文件 | 内容 | 用途 |
|---|---|---|
| `chars/char-*.glb` | 人形角色，至少 2 个 | 玩家和对手 |
| `props/revolver.glb` | 左轮手枪 | 俄罗斯轮盘 |

角色是**人**（酒馆赌客），不是动物。风格偏低模 / 卡通写实都可以，但要统一。

---

## 二、角色模型规格（每个都要满足）

| 项 | 要求 | 为什么 |
|---|---|---|
| 格式 | `.glb` 单文件，贴图**内嵌** | 分开发容易漏 bin/png |
| 身高 | 1.70 – 1.85 m | 桌子高度按这个比例定 |
| 落地 | 脚底 **y = 0** | 否则人会浮空或陷进地里 |
| 朝向 | 面朝 **+Z** | 决定他面对桌子还是背对 |
| 根节点缩放 | **1**（不要 100×、17.8×） | 尺寸混乱的头号原因 |
| 面数 | < 8,000 三角面 | 桌上同时有 5 个 |
| 体积 | 单个 < 5 MB | 首屏加载 |
| 材质 | 标准 PBR（metalness / roughness） | 自定义 shader 会在 three 里丢效果 |
| 骨骼 | 需要有（archetype：人形） | 没有就不能做动作 |

### 需要的动画（命名必须完全一致）

| 动画名 | 必需性 | 用途 |
|---|---|---|
| `Idle` | **必需** | 待机 |
| `Sit` | **强烈建议** | 坐在椅子上等牌（没有的话我改骨骼硬掰，腿会僵） |
| `Death` | **强烈建议** | 中弹倒地 |
| `GunShoot` | 建议 | 举枪、扣扳机 |
| `HitReact` | 可选 | 被拆穿时的反应 |
| `Walk` | 可选 | 入场 / 离场 |

> 命名不要出现 `Gun_Shoot` / `GunShoot` 两种写法，也不要在前面加 `Armature|` 前缀（加了我也能容错，但会多一道匹配）。

## 三、道具

| 文件 | 规格 |
|---|---|
| `props/revolver.glb` | 长 0.25–0.30 m；**请注明枪管朝哪个轴、握把朝哪个轴**；木柄 + 金属转轮 |
| `props/chair.glb` | 木椅，座面高约 0.50 m，座面 0.62 × 0.58 m（可选，现在用几何体拼） |
| `props/table.glb` | 圆桌，直径约 5.7 m、桌面高 0.52 m（可选，现在用几何体拼） |
| `props/props.glb` | 酒瓶、酒杯、筹码、烟灰缸（可选） |

桌子尺寸偏大是刻意的：5 个人围坐 + 中间要放牌堆和筹码。

---

## 四、贴图（可选，现在是代码画的）

| 文件 | 规格 |
|---|---|
| `textures/card-back.png` | 512 × 716，无圆角（圆角由几何体做） |
| `textures/card-faces.png` | 牌面图集：52 张或按 13 个点数出图，每张 256 × 358 |

---

## 五、音频（可选）

| 目录 | 内容 |
|---|---|
| `sfx/` | `card-flip.ogg`、`card-slap.ogg`、`click.ogg`（空枪）、`bang.ogg`（枪响）、`revolver-spin.ogg`、`crowd-murmur.ogg` |
| `vo/` | 角色台词配音，按 `<角色id>_<状态>.ogg` 命名，例如 `char-mage_challenge.ogg` |

`sfx` 格式用 `.ogg`（体积小、浏览器支持好），单文件 < 200 KB。
不给音频也行——游戏会用浏览器 TTS 朗读台词，只是没有环境音。

```
assets/
├─ chars/
│  ├─ char-swordsman.glb

│  └─ ...
├─ props/
│  ├─ revolver.glb

├─ textures/
│  ├─ card-back.png
│  └─ card-faces.png

├─ vo/
```

`LICENSE.md` 必须写清每个文件的**来源与许可**（CC0 / CC-BY / 自制），
CC-BY 需要作者署名，我会把它原样放进游戏署名区。

## 七、交付前自检

把素材放进 `apps/web/public/models/` 后运行：

```bash
node scripts/check-assets.mjs
```

它逐文件输出：

```
── char-swordsman.glb
   尺寸 XYZ  1.675 × 1.857 × 0.55     10198 三角面
   底部 Y    -0.001   骨骼 16  材质 11  贴图 0
   动画 24: Death, Gun_Shoot, Idle, Idle_Gun …
   ⚠ 节点自带 100.0× 缩放
```

`✓ 规格正常` 表示可以直接用；带 ⚠ 的按提示修一下即可。

## 八、加了新角色之后，我怎么接

三步，都不涉及引擎：

1. 把 `char-xxx.glb` 放进 `apps/web/public/models/`
2. 在 `apps/web/src/three/models.ts` 加一行：

   ```ts
   xxx: { file: '/models/char-xxx.glb', height: 1.78 },
   ```

   `height` 是期望身高，不给 `scale` 就自动按包围盒归一化。
3. 在 `apps/web/src/data/characters.ts` 加一个角色（名字、称号、性格、台词）。

角色数量随素材数量走，`MIN_PLAYERS / MAX_PLAYERS` 会自动跟着角色池上限变化。

## 九、不满足规格时的兜底

即便素材不完美，我也能救，只是观感会打折：

| 素材问题 | 补救 | 后果 |
|---|---|---|
| 单位不统一 / 带 100× 缩放 | 按包围盒归一化 | 无 |
| 没有 `Sit` 动画 | 覆盖腿骨摆成 L 形 | 腿略僵 |
| 没有动画 | 整体位移 + 几何体补件 | 动作生硬 |
| 朝向不对 | 配置里加 `yaw` 旋转 | 无 |
| 没有贴图 | 用纯色材质 | 显得单薄 |
